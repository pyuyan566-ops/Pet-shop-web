# 派特宠物超市

这是一个温暖可爱的宠物超市网页练习作品。

## 项目功能

- 商品展示
- 商品详情页
- 简易购物车
- 预约咨询表单
- 服务详情页
- 演示登录页面
- 手机端适配

## 使用技术

- HTML
- CSS
- JavaScript

## 本地打开方式

双击 `index.html`，即可在浏览器中查看网页。

## 在线预览

[点击查看派特宠物超市](https://pyuyan566-ops.github.io/Pet-shop-web/)

## 项目说明

这是一个学习用的静态网站作品。
演示登录不会保存用户名或密码；
购物车数据只保存在当前浏览器中。
